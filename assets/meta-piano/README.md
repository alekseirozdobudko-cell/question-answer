# Meta Piano samples

Source: [Meta Open Sound](https://github.com/facebookincubator/Meta-open-sound), Meta Piano collection.

The collection is released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). The app bundles the 88 notes from A0 through C8 at the medium-dynamic `Vel03` layer. These OGG/Opus source files are converted to mono PCM at 22050 Hz and trimmed to five seconds per note for playback.
