# Question and Answer — Вопрос–Ответ

Приложение для тренировки музыкального слуха: бас-гитара, акустическая гитара, два синтезатора и пианино. Expo / React Native, Android и браузер, SDK 57.

## Скачать

[Последний релиз](https://github.com/alekseirozdobudko-cell/question-answer/releases/latest) содержит:

- `Question-and-Answer.apk` — приложение для прямой установки на Android без Expo Go. Это предварительная сборка с тестовой подписью, не для Google Play.
- `Question-and-Answer.html` — браузерная версия одним файлом: скачайте и откройте в современном браузере.
- `Question-and-Answer-web.zip` — статическая веб-сборка для размещения на HTTP-сервере.

Приложение не записывает микрофон и не оценивает исполнение. Встроенные звуки работают без внешнего сервера.

## Запуск

Нужны Node.js 22+ и Expo Go, поддерживающий SDK 57.

```powershell
npm ci
npm run start
```

Телефон и компьютер должны быть в одной Wi-Fi сети. Сканируй QR-код из терминала в Expo Go. Нажми `w` в терминале для браузера либо выполни `npm run web`. По умолчанию сервер использует порт 8081; можно передать `-- --port 8083`.

Если VPN мешает локальному соединению, проверь подключение без него. Эта сборка не изменяет проект Ear Trainer.

## Как заниматься

1. Выбери основной тон и аккорд, лад или свой набор ступеней.
2. Выбери начальную октаву и 1–3 октавы. Для C major от C2 это 3 / 6 / 9 доступных нот. Диапазон E1–G4 рассчитан на 24 лада; если у баса их меньше, выбирай более низкий регистр.
3. Задай уровень, длину вопроса (1–4 такта), максимум нот в такте (2–12), паузу для ответа (1–8 тактов), темп (40–180 BPM). Все такты 4/4.
4. Нажми «Начать практику». Вопрос → пауза → следующий случайный вопрос, без вступлений и ориентиров.
5. Слушай, играй во время паузы, затем смотри на ноты. Они и ступени видны сразу и остаются до следующей фразы. «Повторить» снова играет ту же фразу и даёт полную паузу, затем автоматический цикл продолжается.

Длительность карточки указана в четвертных долях: 1 — четверть, 0.5 — восьмая, 0.25 — шестнадцатая. «Плавный переход» — промежуточный уровень: почти весь такт играются ровные четверти, иногда появляется одна пара восьмых, а мелодия перемещается только к соседней доступной ноте. На последующих уровнях появляются паузы, синкопы и более крупные скачки. Максимум нот ограничивает плотность, но не заставляет каждый такт иметь одинаковое число нот. Смена уровня задаёт пресет длины и плотности; их можно менять отдельно. Выбор диапазона сохраняется.

Встроены 24 типа аккордов, 22 лада/звукоряда, 12 основных тонов и произвольный набор ступеней. Это не каталог всех существующих ладов: свой набор позволяет задать дополнительные. Ступени считаются от основного тона; расширенные аккорды даны в тесном расположении, 9/11/13 обозначают функции. Ноты записываются с учётом ступеней (например, E♯ в F♯ major).

Метроном включён по умолчанию и отбивает каждую долю в вопросе и в течение всего ответа. Его можно выключить одним переключателем. Фоновый дрон — мягкая, слегка пульсирующая тоника выбранной тональности — по желанию непрерывно звучит под мелодией и в паузе. Настройки сохраняются на устройстве. Во время практики они заблокированы — нажми «Стоп», чтобы изменить. При сворачивании приложения или скрытии вкладки практика останавливается. Запись микрофона и автоматическая оценка исполнения не предусмотрены.

## Звук

14 бесплатных записей настоящего электрического баса, встроенных в проект. После загрузки приложения внешние запросы к источнику звука не нужны. Авторство, лицензия и изменения — в CREDITS.md и разделе приложения «О звуке». Весь цикл, включая метроном и паузу, смешивается в PCM заранее; JavaScript-таймеры не запускают отдельные ноты. Следующая фраза готовится во время текущей. В браузере используется Web Audio, на Android — expo-audio с временным WAV-файлом. На границе циклов Android возможна небольшая задержка запуска плеера; это требует проверки на конкретном телефоне.

## Проверка и сборка

```powershell
npm run typecheck
npm test
npm run export:web
npm run export:android
```

`scripts/prepare-samples.mjs` воспроизводимо готовит src/samples.json из WAV-файлов. Изменения исходных записей не нужны. `dist/` после экспорта — статическая веб-сборка, её нужно открыть через HTTP-сервер. Экспорт также создаёт самостоятельный файл `../outputs/Question-and-Answer.html`. Инструкция по APK — в [ANDROID.md](ANDROID.md).
